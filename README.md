# Проєктування Моделювання: Командний проєкт

Це командний проєкт з дисципліни "Проєктування, моделювання та забезпечення якості програмного забезпечення систем" для університету.

## Запуск

1. Встановити [uv](https://docs.astral.sh/uv/);
2. Клонувати репозиторій;
3. Виконати команди:

```
uv sync
```

/\ - Для завантаження залежностей проєкту.

```
python manage.py runserver
```

/\ - Для запуску застосунку у браузері.
